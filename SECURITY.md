# Security Policy

## Supported Versions
Security updates are provided for the following versions:
| Version | Supported |
| ------- | --------- |
| >= 1.0.0 | ✅ |

## Reporting a Vulnerability
To report a vulnerability, please open a draft security advisory at:
https://github.com/Kockerpro94/repository-security-baseline/security/advisories/new
