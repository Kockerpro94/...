# Security Policy

## Supported Versions

Security updates are provided for the following versions:

| Version | Supported          |
| ------- | ------------------ |
| >= 1.0.0 | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability, please report it via the [GitHub Security Advisory page](https://github.com/Kockerpro94/repository-security-baseline/security/advisories/new) by opening a draft security advisory.
