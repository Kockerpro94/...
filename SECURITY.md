# Security Policy

## Reporting a Vulnerability

We take the security of this project seriously. If you believe you have found a security vulnerability, please report it to us as soon as possible.

The preferred method for reporting a vulnerability is by opening a draft Security Advisory on GitHub:
https://github.com/Kockerpro94/repository-security-baseline/security/advisories/new

We will aim to acknowledge your report within 48 hours.
