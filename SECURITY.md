# Security Policy

## Supported Versions

Security updates are provided for the following versions:

| Version | Supported          |
| ------- | ------------------ |
| >= 1.0.0 | :white_check_mark: |

## Reporting a Vulnerability

Please report vulnerabilities by opening a draft security advisory at:
https://github.com/Kockerpro94/repository-security-baseline/security/advisories/new
