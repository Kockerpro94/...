# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please report it immediately.

Please do NOT open a public issue. Instead, use the following method:

1. Go to the [Security Advisories](https://github.com/Kockerpro94/repository-security-baseline/security/advisories) page.
2. Click on "New draft security advisory".
3. Provide details of the vulnerability and steps to reproduce.
