# Security Policy

## Supported Versions

The following versions are currently supported with security updates:

| Version | Supported          |
| ------- | ------------------ |
| >= 1.0.0 | :white_check_mark: |

## Reporting a Vulnerability

We take the security of our project seriously. If you believe you've found a security vulnerability, please report it by opening a draft security advisory at:

https://github.com/Kockerpro94/repository-security-baseline/security/advisories/new

We aim to acknowledge all reports within 48 hours.
